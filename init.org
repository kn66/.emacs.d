* このファイルの使い方

このファイルを Emacs 設定の編集元とします。各節の説明に続く Emacs Lisp を
上から順に =init.el= へ書き出します。設定は機能ごとの =use-package= 宣言にまとめています。
Emacs 30.2 と Emacs 31 の組み込み機能を中心に、補完・検索・テンプレート・
編集履歴・Git 操作を外部パッケージで拡張しています。
同じ設定を両環境で使い、バージョン差がある箇所は自動で切り替えます。

設定を変更したら、このファイルで =C-c C-v t= （=org-babel-tangle=）を実行し、
生成された =init.el= を次回の Emacs 起動時に読み込ませてください。
起動時の Org 読み込みや自動生成は行いません。
=init.el= を直接編集すると、次回の生成時にその変更が上書きされます。
=M-x customize= などによる保存値は =custom.el= に分離し、起動時に読み込みます。
このファイルにはマシン固有の値も含まれるため Git の管理対象外にします。

コマンドラインから生成する場合は、Emacs 設定ディレクトリで次を実行します。
このシェルブロックは =init.el= への書き出し対象外です。

#+begin_src sh :tangle no
  emacs -Q --batch --eval "(require 'org)" --eval '(org-babel-tangle-file "init.org")'
#+end_src

* use-package の準備

Emacs 30.2 / 31 に同梱されている =use-package= を読み込みます。
外部パッケージは原則として GNU ELPA・NonGNU ELPA・MELPA から取得します。
Magit・gptel・solarized-theme は NonGNU ELPA、Puni・Nucleo・Migemo・Copilot・consult-dir・
Emacs 31.1 以上の =tempel-collection= は MELPA、
それ以外は各宣言で GNU ELPA を指定します。
アーカイブに未収録の =dired-clipboard= は公式リポジトリから取得します。
=tempel-collection= は Emacs 31.1 以上では MELPA から導入します。
それ以前の Emacs では例外として公式リポジトリから取得し、互換版に固定します。
各宣言の =:ensure nil= は、通常のパッケージアーカイブからのインストールを行わない指定です。
組み込み・ローカルのライブラリ、または =:vc= で導入するパッケージに使用します。
=:custom= に変数、=:hook= にフック、=:bind= にキー割り当て、
=:config= に読み込み後の処理をまとめます。
=:preface= で他の設定が参照する変数を先に定義し、=:init= で保存先を作成します。
=:defer t= の機能は必要になるまで読み込みを遅らせ、
起動時に有効にするモードには =:demand t= を指定します。

Emacs 31.1 以降では =package-review-policy= を =t= にし、
パッケージアーカイブからのインストール・更新前にレビューを行います。
更新時の確認で =d= を押すと旧版との差分、=b= でソース、
変更履歴がある場合は =c= でその内容を表示できます。
=y= でインストールを進め、=n= でそのパッケージを中止します。
新規インストールでは比較対象の旧版がないため、差分の選択肢は出ません。
このレビューは =package-vc= による取得・更新には適用されません。
Emacs 30.2 では設定項目がないため、有効化をスキップします。

#+begin_src emacs-lisp
  ;;; init.el --- 個人用 Emacs 設定 -*- lexical-binding: t; -*-
  ;; このファイルは init.org から生成します。設定の変更は init.org で行ってください。

  (setq custom-file (locate-user-emacs-file "custom.el"))

  (require 'use-package)

  (use-package package
    :ensure nil
    :demand t
    :config
    (add-to-list 'package-archives '("melpa" . "https://melpa.org/packages/") t)
    (when (boundp 'package-review-policy)
      (setopt package-review-policy t)))
#+end_src

* Emacs の基本設定

特定のライブラリに属さない基本設定を =emacs= の宣言へまとめます。

** 確認・検索・ミニバッファ・スクロール

- =use-short-answers=: yes/no の確認に y/n で答えられるようにします。
- =isearch-lazy-count=: インクリメンタル検索で現在位置と一致件数を表示します。
- =enable-recursive-minibuffers=: ミニバッファの使用中にも、ミニバッファを使う別の操作を許可します。
- =help-window-select=: 新しく開いたヘルプウィンドウを選択します。
- =mouse-yank-at-point=: 中クリックの貼り付け先を、マウス位置ではなくカーソル位置にします。
- =scroll-preserve-screen-position=: スクロール時にカーソルの画面内位置をできるだけ維持します。
- =scroll-error-top-bottom=: スクロールでこれ以上移動できなくなる前に、バッファの先頭・末尾へ移動します。

** 検索を続けながらスクロールする

=isearch-allow-scroll= により、インクリメンタル検索を終了せずに
=C-v= / =M-v= や =C-l= を使えます。検索を再開しやすいよう、一致箇所を表示範囲に保ちます。

** クリップボードとキルリング

=save-interprogram-paste-before-kill= で、Emacs のコピーや切り取りによって
上書きされる前のクリップボード内容をキルリングへ保存します。
=kill-do-not-save-duplicates= で、同じ内容をキルリングへ重複して保存することを抑えます。

** 補完候補の詳細と診断の強調

=completions-detailed= で補完候補に説明などの詳細を表示します。
=next-error-message-highlight= で、エラー移動時に対応するコンパイル出力の診断を強調します。

** M-x の候補をモードに合わせる

=read-extended-command-predicate= に =command-completion-default-include-p= を指定し、
他のモード専用と明示されたコマンドを =M-x= の候補から除外します。

** キー割り当て一覧の折りたたみ

=describe-bindings-outline= により、=C-h b= のキー割り当て一覧を
見出しごとに折りたためるようにします。見出し上の =TAB= で表示を切り替えます。

** 式の評価結果の表示量

=M-:= などで表示する値について、=eval-expression-print-length= を50、
=eval-expression-print-level= を10にします。
長いリストや深い入れ子を確認しやすくしつつ、巨大な出力には上限を設けます。

** TAB 補完と大文字・小文字の扱い

- =tab-always-indent=: まず字下げし、字下げが済んでいれば =TAB= で補完します。
- =completion-ignore-case=: 通常の補完で大文字と小文字を区別せず照合します。
- =read-file-name-completion-ignore-case=: ファイル名の補完で大文字と小文字を区別せず照合します。
- =read-buffer-completion-ignore-case=: バッファ名の補完で大文字と小文字を区別せず照合します。

候補そのものの大文字・小文字は維持します。

** 列番号とミニバッファの深さ

=column-number-mode= で列番号を表示し、
=minibuffer-depth-indicate-mode= でミニバッファが入れ子になったときの深さを表示します。

** カーソルの表示

=cursor-type= を幅 3 ピクセルの縦線にし、=blink-cursor-mode= を無効にして点滅させません。
テーマ読み込み後にカーソル色をマゼンタ（=#d33682=）に設定します。
=global-hl-line-mode= でカーソルのある行を強調します。

** ファイル削除・改行・字下げ

バックアップ設定から、=delete-by-moving-to-trash= と =require-final-newline= を取り入れます。
ファイル削除時は利用できるシステムのゴミ箱へ移し、テキストの保存時は末尾に改行を補います。
リモートファイルなどではゴミ箱の扱いが異なるため、削除時の確認に従ってください。
既定の字下げは空白にし、Makefile などのモード指定や EditorConfig の指定を優先します。

** 新規バッファの文字コード

新しく作るバッファの保存時の文字コードは UTF-8 を既定にします。
改行コードはここで固定せず、既存ファイルを開くときはその文字コードを判定します。

** 基本設定の宣言

#+begin_src emacs-lisp
  (use-package emacs

    :demand t
    :custom
    (use-short-answers t)
    (isearch-lazy-count t)
    (enable-recursive-minibuffers t)
    (help-window-select t)
    (mouse-yank-at-point t)
    (scroll-preserve-screen-position t)
    (scroll-error-top-bottom t)
    (isearch-allow-scroll t)
    (save-interprogram-paste-before-kill t)
    (kill-do-not-save-duplicates t)
    (mark-ring-max 64)
    (global-mark-ring-max 64)
    (completions-detailed t)

* フォント

Windows と Fedora の GUI フレームでは共通のフォントを指定します。
英数字・日本語とも、通常表示の =default= と等幅表示の =fixed-pitch= に
=PlemolJP=、可変幅表示の =variable-pitch= に =IBM Plex Sans JP= を使います。
=PlemolJP= は半角と全角の幅が 1:2 の通常版です。
通常の編集は等幅で表示し、可変幅表示を使うモードでは =variable-pitch= を参照します。
日本語も各 face のフォントで表示するため、日本語フォントを
フォントセット全体へ固定しません。
通常表示の大きさは従来どおり 11pt とし、等幅・可変幅表示もその大きさに合わせます。
フォントがない環境では該当する設定を省き、端末では設定しません。
新しく作成したフレームにも同じ設定を適用します。

Windows の両フォントはインストール済みです。Fedora などへ導入する場合は、
次の公式ダウンロード先から両フォントを取得します。

- [[https://github.com/yuru7/PlemolJP/releases/latest][PlemolJP の最新リリース]]: Assets から通常版の =PlemolJP_v*.zip= を取得し、
  展開後に =35= や =Console= が付かない =PlemolJP= のフォントを選びます。
- [[https://github.com/IBM/plex/releases][IBM Plex の公式リリース一覧]]: =IBM Plex Sans JP= のリリースを探し、
  Assets から日本語版のフォント ZIP を取得します。

どちらも Windows と Fedora で利用できます。
設定ではファイル名ではなく、フォントファミリー名を指定します。

#+begin_src emacs-lisp
  (use-package faces
    :ensure nil
    :demand t
    :config
    (defun my-setup-frame-fonts (frame)
      "Set shared fixed and variable fonts on graphical FRAME."
      (when (and (memq system-type '(windows-nt gnu/linux))
                 (display-graphic-p frame))
        (with-selected-frame frame
          (let ((families (font-family-list)))
            (when (member "PlemolJP" families)
              (set-face-attribute 'default frame :family "PlemolJP" :height 110)
              (set-face-attribute 'fixed-pitch frame
                                  :family "PlemolJP" :height 1.0))
            (when (member "IBM Plex Sans JP" families)
              (set-face-attribute 'variable-pitch frame
                                  :family "IBM Plex Sans JP" :height 1.0))))))
    (add-hook 'after-make-frame-functions #'my-setup-frame-fonts)
    (my-setup-frame-fonts (selected-frame)))
#+end_src

* 日本語入力

GUI 版 Emacs では OS の日本語入力を使います。Emacs 内蔵の入力方式は
設定しません。=C-\= は Emacs 内蔵の入力方式の切替であり、OS の IME
の切替には使いません。

** Windows

ネイティブ版 Emacs では Microsoft IME を使います。Windows の
「日本語 - Microsoft IME」を有効にし、Windows 側のキーで日本語入力を
切り替えます。Emacs への追加パッケージは不要です。
[[https://www.gnu.org/software/emacs/manual/html_node/emacs/Windows-Keyboard.html][Emacs マニュアル]]に Windows IME への対応が記載されています。

** Fedora GNOME（Wayland / Fcitx 5）

この環境では Fcitx 5 + Mozc と =emacs-pgtk= を使います。
GTK の入力方式を ~GTK_IM_MODULE=fcitx~ に設定したデスクトップセッションで
Emacs を起動してください。現在の環境にはこの設定と Mozc の登録があります。
X11 版 Emacs では ~XMODIFIERS=@im=fcitx~ の設定も認識します。

Fcitx 5 の [[https://github.com/fcitx/fcitx5/blob/master/src/modules/dbus/dbusmodule.cpp][D-Bus コントローラー]]を使い、入力状態の取得とオン・オフを行います。
Emacs に追加パッケージは不要ですが、D-Bus 対応の Emacs が必要です。
外部コマンドをキー入力のたびに起動せず、Emacs から直接通信します。
Fcitx 5 が未起動の場合、端末フレーム、IBus を使う環境では自動制御を行いません。

** コマンド操作中の英字入力（Windows / Fedora 共通）

ミニバッファに入るときは IME の状態を保存して英字入力に切り替えます。
ミニバッファ内で日本語が必要なときは手動で IME をオンにできます。
確定または =C-g= でミニバッファを抜けたら、入る前の状態に戻します。
入れ子のミニバッファでは各入力欄の状態を別々に保存します。
=C-x= / =C-c= / =C-h= / =M-g= / =M-s= の後に続く英字もコマンドとして
読めるよう、プレフィックスキーを受けた時点で IME を一時的にオフにします。
コマンド終了後は元の状態に戻し、コマンドがミニバッファを開く場合は
保存した状態をミニバッファへ引き継ぎます。
=repeat-mode= のキー列が続く間も英字入力を保ち、2 秒間操作がなければ
繰り返しを終了して元の IME 状態へ戻します。読み取り専用バッファへ
移ったときは IME をオフにし、編集可能なバッファへ戻ったら復元します。
読み取り専用バッファでの日本語検索は手動で IME をオンにでき、検索を
終えたら再びオフにします。Fedora では Emacs にフォーカスがある間だけ
制御し、他のアプリを操作中に繰り返し終了タイマーが IME を変更することを防ぎます。

#+begin_src emacs-lisp
  (use-package minibuffer
    :ensure nil
    :if (memq system-type '(windows-nt gnu/linux))
    :config
    (defvar my-ime-prefix-state nil
      "Saved (BUFFER . STATUS) for an IME key prefix.")

    (defvar my-ime-last-editable-state nil
      "Last IME status observed in an editable buffer.")

    (defvar my-ime-readonly-state nil
      "IME status to restore after leaving read-only buffers.")

    (defvar-local my-minibuffer-ime-open-status nil
      "Saved IME status for this minibuffer invocation.")

    (when (eq system-type 'gnu/linux)
      (require 'dbus nil t))

    (defun my-ime-fcitx5-call (method)
      "Call Fcitx 5 controller METHOD without starting an IME daemon.
  Return nil if the session bus or controller is unavailable.  Bound each
  D-Bus call to 100 milliseconds so command hooks cannot wait indefinitely."
      (when (fboundp 'dbus-call-method)
        (condition-case nil
            (let ((owner (dbus-call-method
                          :session "org.freedesktop.DBus"
                          "/org/freedesktop/DBus" "org.freedesktop.DBus"
                          "GetNameOwner" :timeout 100 "org.fcitx.Fcitx5")))
              (when owner
                (dbus-call-method
                 :session owner "/controller" "org.fcitx.Fcitx.Controller1"
                 method :timeout 100)))
          (error nil))))

    (defun my-ime-available-p ()
      "Return non-nil when the selected GUI frame supports IME control."
      (and (display-graphic-p)
           (pcase system-type
             ('windows-nt
              (and (fboundp 'w32-get-ime-open-status)
                   (fboundp 'w32-set-ime-open-status)))
             ('gnu/linux
              ;; The controller operates on the most recent input context.
              ;; Never change another application's IME from a repeat timer.
              (and (eq (frame-focus-state) t)
                   (or (equal (getenv "GTK_IM_MODULE") "fcitx")
                       (and (eq window-system 'x)
                            (equal (getenv "XMODIFIERS") "@im=fcitx")))
                   (memq (my-ime-fcitx5-call "State") '(1 2)))))))

    (defun my-ime-get-open-status ()
      "Return non-nil if the OS IME is active on the selected frame."
      (pcase system-type
        ('windows-nt (w32-get-ime-open-status))
        ('gnu/linux (eq (my-ime-fcitx5-call "State") 2))))

    (defun my-ime-set-open-status (status)
      "Set the selected frame's OS IME to STATUS."
      (pcase system-type
        ('windows-nt (w32-set-ime-open-status status))
        ('gnu/linux
         (when (eq (frame-focus-state) t)
           (my-ime-fcitx5-call (if status "Activate" "Deactivate"))))))

    (defun my-ime-prefix-translation (key)
      "Return a translation for KEY that turns off the IME first."
      (lambda (&optional _prompt)
        (when (and (my-ime-available-p)
                   (null my-ime-prefix-state))
          (setq my-ime-prefix-state
                (cons (current-buffer) (my-ime-get-open-status)))
          (my-ime-set-open-status nil))
        key))

    (defun my-ime-restore-prefix ()
      "Restore the IME saved before a command prefix or repeat sequence."
      (when my-ime-prefix-state
        (let ((status (cdr my-ime-prefix-state)))
          (setq my-ime-prefix-state nil)
          (when (my-ime-available-p)
            (my-ime-set-open-status status))
          (unless (or (minibufferp) buffer-read-only)
            (setq my-ime-last-editable-state (cons t status))))))

    (defun my-ime-before-command ()
      "Remember the user's IME state while editing writable text."
      (when (and (my-ime-available-p)
                 (not (minibufferp))
                 (not buffer-read-only))
        (setq my-ime-last-editable-state
              (cons t (cond (my-ime-prefix-state
                             (cdr my-ime-prefix-state))
                            (my-ime-readonly-state
                             (cdr my-ime-readonly-state))
                            ((bound-and-true-p repeat-in-progress)
                             (if my-ime-last-editable-state
                                 (cdr my-ime-last-editable-state)
                               (my-ime-get-open-status)))
                            (t (my-ime-get-open-status)))))))

    (defun my-ime-after-command ()
      "Keep command-only buffers and repeat keys in English."
      (when (and (my-ime-available-p) (not (minibufferp)))
        (cond
         (buffer-read-only
          (unless my-ime-readonly-state
            (setq my-ime-readonly-state
                  (or (and my-ime-prefix-state
                           (cons t (cdr my-ime-prefix-state)))
                      my-ime-last-editable-state
                      (cons t (my-ime-get-open-status))))
            (my-ime-set-open-status nil))
          (setq my-ime-prefix-state nil))
         (my-ime-readonly-state
          (let ((status (cdr my-ime-readonly-state)))
            (setq my-ime-readonly-state nil
                  my-ime-last-editable-state (cons t status))
            (if (bound-and-true-p repeat-in-progress)
                (progn
                  (setq my-ime-prefix-state
                        (cons (current-buffer) status))
                  (my-ime-set-open-status nil))
              (setq my-ime-prefix-state nil)
              (my-ime-set-open-status status))))
         ((bound-and-true-p repeat-in-progress)
          (unless my-ime-prefix-state
            (setq my-ime-prefix-state
                  (cons (current-buffer)
                        (if my-ime-last-editable-state
                            (cdr my-ime-last-editable-state)
                          (my-ime-get-open-status))))
            (my-ime-set-open-status nil)))
         (t (my-ime-restore-prefix)))))

    (defun my-ime-after-repeat-exit (&rest _)
      "Restore the IME when a repeat sequence ends while editing."
      (unless (or (minibufferp) buffer-read-only my-ime-readonly-state)
        (my-ime-restore-prefix)))

    (defun my-ime-after-isearch ()
      "Turn the IME off again after searching a read-only buffer."
      (when (and (my-ime-available-p)
                 buffer-read-only
                 my-ime-readonly-state)
        (my-ime-set-open-status nil)))

    (defun my-ime-install-prefix-keys (&optional frame)
      "Translate command prefixes on graphical FRAME."
      (when (display-graphic-p frame)
        (with-selected-frame (or frame (selected-frame))
          (dolist (name '("C-x" "C-c" "C-h" "M-g" "M-s"))
            (let ((key (kbd name)))
              (unless (lookup-key input-decode-map key)
                (define-key input-decode-map key
                  (my-ime-prefix-translation key))))))))

    (defun my-minibuffer-disable-ime ()
      "Save the IME state and turn it off in the minibuffer."
      (when (my-ime-available-p)
        (setq-local my-minibuffer-ime-open-status
                    (cons t (if my-ime-prefix-state
                                (prog1 (cdr my-ime-prefix-state)
                                  (setq my-ime-prefix-state nil))
                              (my-ime-get-open-status))))
        (my-ime-set-open-status nil)))

    (defun my-minibuffer-restore-ime ()
      "Restore the IME state saved before minibuffer entry."
      (when (my-ime-available-p)
        (when (eq (car-safe my-ime-prefix-state) (current-buffer))
          (setq my-ime-prefix-state nil))
        (when (car-safe my-minibuffer-ime-open-status)
          (my-ime-set-open-status (cdr my-minibuffer-ime-open-status))
          (setq-local my-minibuffer-ime-open-status nil))))

    (add-hook 'minibuffer-setup-hook #'my-minibuffer-disable-ime)
    (add-hook 'minibuffer-exit-hook #'my-minibuffer-restore-ime)
    (add-hook 'pre-command-hook #'my-ime-before-command)
    (add-hook 'post-command-hook #'my-ime-after-command t)
    (add-hook 'isearch-mode-end-hook #'my-ime-after-isearch)
    (add-hook 'after-make-frame-functions #'my-ime-install-prefix-keys)
    (my-ime-install-prefix-keys)
    (my-ime-before-command)
    (my-ime-after-command))
#+end_src

* Nucleo による補完候補の照合

補完候補の日本語 Migemo 照合を有効にします。辞書はモジュールへ同梱されており、

Nucleo のスコアが同点の候補は、ミニバッファの入力履歴、または

#+begin_src emacs-lisp
  (use-package nucleo-completion
    :ensure t
    :pin melpa
    :demand t
    :preface
    (defun my-nucleo-completion-category-defaults (categories)
      "Return CATEGORIES with Nucleo preferred for ordinary completion."
      (let ((defaults (copy-tree categories)))
        (dolist (category defaults defaults)
          (let ((styles (assq 'styles (cdr category))))
            ;; External styles own their candidate retrieval and must stay first.
            (when (and styles (not (memq 'external (cdr styles))))
              (setcdr styles
                      (cons 'nucleo
                            (remq 'nucleo (remq 'flex (cdr styles))))))))))

    :custom
    (completion-styles '(nucleo basic))
    (nucleo-completion-languages '(japanese))
    (nucleo-completion-sort-ties-by-history t)
    (nucleo-completion-sort-ties-alphabetically t)
    :config
    (nucleo-completion-ensure-module)
    (setq completion-category-defaults
          (my-nucleo-completion-category-defaults completion-category-defaults)))
#+end_src

* バッファ内の補完

[[https://github.com/minad/corfu#configuration][Corfu README の設定例]]に沿って、バッファ内の =completion-at-point= の候補をポップアップで表示します。
=M-TAB=、または字下げ済みの位置で =TAB= を押すと手動で補完を開始します。
候補は最大12件、幅は24〜80文字で表示し、一覧の端から次へ進むと循環します。
先頭候補を自動選択し、=RET= で確定します。候補のプレビューは無効にします。
候補の照合には既存の Nucleo と basic を使います。
ミニバッファでは Vertico を使います。
Emacs 30 のポップアップは GUI で利用でき、端末では標準の補完表示にフォールバックします。
[[https://github.com/minad/corfu#readme][Emacs 31 では端末の子フレームにも対応]]しており、同じ設定で端末にもポップアップを表示できます。
既存の =global-completion-preview-mode= は表示が重複するため無効にします。

補完一覧を表示中は次のキーを使います。

| キー | 操作 |
|------+------|
| =C-n= / =M-n= / 下矢印 | 次の候補 |
| =C-p= / =M-p= / 上矢印 / =Shift-TAB= | 前の候補 |
| =TAB= | Copilot の提案があれば確定。なければ共通部分や選択中の候補を補完 |
| =RET= | 選択した候補を確定 |
| =M-q= | 候補に表示された短いキーを入力して直接確定 |
| =M-h= / =M-g= | 候補の説明 / 定義位置を表示 |
| =M-t= | 説明ポップアップの表示切り替え |
| =C-M-v= / =C-M-S-v= | 説明ポップアップを下 / 上へスクロール |
| =C-g= | 補完を中止 |

** Cape による補完候補の追加

[[https://github.com/minad/cape#configuration][Cape README の設定例]]に沿って、=C-c p= を各補完コマンドのプレフィックスにします。
=C-c p ?= で一覧を確認できます。各モードの設定が完了した後、モード既定の CAPF と
=tempel-complete=、=cape-dabbrev= を =cape-capf-super= で組み合わせます。
モードの補完候補、テンプレート名、バッファ内の単語を同じ候補一覧に表示します。
=ispell-completion-at-point= は辞書がない環境でエラーになるため、統合対象から除外します。
CAPF 内の =t= はグローバルの補完関数に展開し、繰り返し設定しても二重に包みません。
ミニバッファは対象外とし、ファイル名と Org 内の Emacs Lisp コードブロックの
補完は従来どおり先に試します。Cape は補完の開始位置が同じ候補を統合します。

#+begin_src emacs-lisp
  (use-package cape
    :ensure t
    :pin gnu
    :demand t
    :bind ("C-c p" . cape-prefix-map)
    :config
    (defvar-local my-cape-super-capf nil
      "Merged completion function for the current major mode.")

    (defun my-cape-setup-capf ()
      "Merge the mode's completion functions with Tempel and dabbrev."
      (unless (or (minibufferp)
                  (and my-cape-super-capf
                       (memq my-cape-super-capf completion-at-point-functions)))
        (let ((capfs
               (mapcan (lambda (capf)
                         (if (eq capf t)
                             (copy-sequence
                              (default-value 'completion-at-point-functions))
                           (list capf)))
                       completion-at-point-functions)))
          (setq-local my-cape-super-capf
                      (apply #'cape-capf-super
                             (delete-dups
                               (append (remq #'ispell-completion-at-point capfs)
                                      (list #'tempel-complete #'cape-dabbrev))))
                      completion-at-point-functions
                      (list #'cape-elisp-block #'cape-file my-cape-super-capf)))))

    (add-hook 'after-change-major-mode-hook #'my-cape-setup-capf))
#+end_src

* GitHub Copilot による入力補助

[[https://github.com/copilot-emacs/copilot.el][copilot.el]] を MELPA から導入し、プログラミング用および文章用バッファで
提案を表示します。=TAB= で提案全体、=C-TAB= または =C-c C-f= で次の単語を確定します。
Corfu の候補一覧と同時に表示されている場合も、=TAB= は Copilot の確定を優先します。
Corfu の候補は =C-n= / =C-p= または上下キーで選び、=RET= で確定します。
候補を移動している間も Copilot の提案を残すため、見比べてから =TAB= で採用できます。
Copilot の提案がないときの =TAB= は通常の字下げや補完を行います。
=M-n= / =M-p= は Corfu の一覧表示中は Corfu の候補移動、それ以外は Copilot の提案切り替えに使います。
従来の =C-c TAB=、=C-c M-n= / =C-c M-p= も引き続き使えます。
初回は =M-x copilot-install-server= と =M-x copilot-login= を実行し、
GitHub Copilot にサインインしてください。

間接バッファでは本文が共有されるため、Copilot の変更追跡は同じ本文につき
一つだけ有効にします。=org-capture=、=org-tree-to-indirect-buffer=、
=clone-indirect-buffer= などで複製した直後に追跡状態を分離し、編集するバッファで
追跡を新しく開始します。元バッファと間接バッファを行き来すると自動で切り替わり、
Lisp から別バッファを編集する場合も変更前に切り替えます。
別のバッファで編集された内容は、再開時に全文を送って Copilot に反映します。
手動で Copilot を無効にしたバッファは、自動再開の対象にしません。
接続が切れている場合は変更フックからサーバーを起動せず、追跡を停止して本文の編集を
続けられるようにします。切替時の接続エラーは警告に残し、次の操作で再開を試みます。

#+begin_src emacs-lisp :tangle no
  (use-package copilot
    :ensure t
    :pin melpa
    :hook ((prog-mode . copilot-mode)
           (text-mode . copilot-mode))
    :bind (:map copilot-completion-map
                ("TAB" . copilot-accept-completion)
                ("<tab>" . copilot-accept-completion)
                ("C-c TAB" . copilot-accept-completion)
                ("C-c <tab>" . copilot-accept-completion)
                ("C-c C-f" . copilot-accept-completion-by-word)
                ("C-c M-n" . copilot-next-completion)
                ("C-c M-p" . copilot-previous-completion))
    :config
    (dolist (command '(corfu-next corfu-previous))
      (add-to-list 'copilot-clear-overlay-ignore-commands command))

    ;; Let Corfu handle candidate navigation while its completion is active.
    (dolist (binding '(("M-n" . copilot-next-completion)
                       ("M-p" . copilot-previous-completion)))
      (keymap-set copilot-completion-map (car binding)
                  `(menu-item "" ,(cdr binding)
                              :filter (lambda (command)
                                        (unless (bound-and-true-p completion-in-region-mode)
                                          command)))))

    (defvar my-copilot-indirect-switching nil
      "Non-nil while transferring Copilot between buffers sharing text.")

    (defvar my-copilot-indirect-closing nil
      "Buffer being closed, excluded when choosing the next Copilot buffer.")

    (defvar-local my-copilot-indirect-root nil
      "Base buffer of a managed group of buffers sharing text.")

    (defvar-local my-copilot-indirect-enabled nil
      "Non-nil when the user wants Copilot in this managed buffer.")

    (defun my-copilot-indirect-members (root)
      "Return live, enabled Copilot buffers sharing ROOT's text."
      (seq-filter
       (lambda (buffer)
         (and (not (eq buffer my-copilot-indirect-closing))
              (with-current-buffer buffer
                (and (eq my-copilot-indirect-root root)
                     my-copilot-indirect-enabled))))
       (buffer-list)))

    (defun my-copilot-indirect-activate (buffer)
      "Make BUFFER the only active Copilot buffer for its shared text."
      (when (buffer-live-p buffer)
        (with-current-buffer buffer
          (when my-copilot-indirect-enabled
            (let ((my-copilot-indirect-switching t))
              (dolist (other (my-copilot-indirect-members
                             my-copilot-indirect-root))
                (unless (eq other buffer)
                  (my-copilot-indirect-pause other)))
              (unless (bound-and-true-p copilot-mode)
                ;; A fresh tracker and didOpen resynchronize the whole text.
                (copilot-mode 1)))))))

    (defun my-copilot-indirect-resume (root)
      "Resume an enabled member of ROOT after a buffer closes or is disabled."
      (let* ((members (my-copilot-indirect-members root))
             (active (seq-find
                      (lambda (buffer)
                        (buffer-local-value 'copilot-mode buffer))
                      members)))
        (my-copilot-indirect-try-activate
         (or active (and (memq (current-buffer) members) (current-buffer))
             (car members)))))

    (defun my-copilot-indirect-pause (buffer)
      "Stop BUFFER's tracker even if closing its server document fails."
      (with-current-buffer buffer
        (when (or (bound-and-true-p copilot-mode) copilot--track-changes-id)
          (let ((my-copilot-indirect-switching t))
            (condition-case err
                (copilot-mode -1)
              (error
               ;; Cancelling a completion can fail before mode teardown runs.
               ;; Teardown removes our hooks and tracker before sending didClose.
               (condition-case close-error
                   (copilot--mode-teardown)
                 (error
                  (display-warning 'copilot
                                   (error-message-string close-error))))
               (when (and copilot--track-changes-id
                          (memq copilot--track-changes-id track-changes--trackers))
                 (track-changes-unregister copilot--track-changes-id))
               (setq-local copilot-mode nil copilot--track-changes-id nil)
               (display-warning 'copilot (error-message-string err))))))))

    (defun my-copilot-indirect-try-activate (buffer)
      "Activate BUFFER, keeping editor hooks usable on connection failures."
      (condition-case err
          (progn (my-copilot-indirect-activate buffer)
                 (and (buffer-live-p buffer)
                      (buffer-local-value 'copilot-mode buffer)))
        (error
         (when (buffer-live-p buffer)
           (my-copilot-indirect-pause buffer))
         (display-warning 'copilot
                          (format "Copilot switching paused: %s"
                                  (error-message-string err)))
         nil)))

    (defun my-copilot-indirect-before-command ()
      "Resume Copilot when returning to a managed buffer."
      (when (and my-copilot-indirect-enabled
                 (not (bound-and-true-p copilot-mode)))
        (my-copilot-indirect-try-activate (current-buffer))))

    (defun my-copilot-indirect-before-change (beg end)
      "Switch tracking before a Lisp edit of an inactive buffer at BEG..END."
      ;; A non-cloned indirect buffer has no inherited local hooks or modes.
      (when (and (not my-copilot-indirect-root) (buffer-base-buffer))
        (let ((root (buffer-base-buffer)))
          (when (or (buffer-local-value 'copilot-mode root)
                    (buffer-local-value 'my-copilot-indirect-root root)
                    (my-copilot-indirect-members root))
            (when (buffer-local-value 'copilot-mode root)
              (my-copilot-indirect-manage root root t))
            (my-copilot-indirect-manage (current-buffer) root copilot-mode))))
      (when my-copilot-indirect-root
        (if (or (not my-copilot-indirect-enabled)
                (and (not (bound-and-true-p copilot-mode))
                     (not (copilot--connection-alivep))))
            ;; A disabled view can still change the shared text. Stop other
            ;; trackers so they restart from the new text next time. Never
            ;; start a disconnected server from inside a text-change hook.
            (dolist (other (my-copilot-indirect-members
                           my-copilot-indirect-root))
              (my-copilot-indirect-pause other))
          (unless (bound-and-true-p copilot-mode)
            (when (my-copilot-indirect-try-activate (current-buffer))
              ;; The new before hook may not be in this run's hook list yet.
              (when copilot--track-changes-id
                (track-changes--before beg end)))))))

    (defun my-copilot-indirect-release ()
      "Resume a remaining buffer after Copilot has closed this document."
      (let ((my-copilot-indirect-closing (current-buffer)))
        (my-copilot-indirect-resume my-copilot-indirect-root)))

    (defun my-copilot-indirect-manage (buffer root enabled)
      "Manage BUFFER as a member of ROOT, respecting ENABLED."
      (with-current-buffer buffer
        (setq-local my-copilot-indirect-root root
                    my-copilot-indirect-enabled enabled)
        (add-hook 'clone-indirect-buffer-hook
                  #'my-copilot-indirect-cloned -100 t)
        (add-hook 'before-change-functions
                  #'my-copilot-indirect-before-change -100 t)
        (add-hook 'kill-buffer-hook #'my-copilot-indirect-release 90 t)))

    (defun my-copilot-indirect-mode-changed ()
      "Remember explicit mode changes and manage newly enabled indirect buffers."
      (unless my-copilot-indirect-switching
        (when copilot-mode
          (add-hook 'clone-indirect-buffer-hook
                    #'my-copilot-indirect-cloned -100 t))
        (when (or (buffer-base-buffer) my-copilot-indirect-root
                  (my-copilot-indirect-members (current-buffer)))
          (let ((root (or (buffer-base-buffer) (current-buffer))))
            (when (and (not (eq root (current-buffer)))
                       (buffer-local-value 'copilot-mode root))
              (my-copilot-indirect-manage root root t))
            (my-copilot-indirect-manage (current-buffer) root copilot-mode)
            (if copilot-mode
                (my-copilot-indirect-activate (current-buffer))
              (my-copilot-indirect-resume root))))))

    (defvar-local my-copilot-indirect-initialized nil
      "Buffer whose copied Copilot state has already been detached.")

    (defun my-copilot-indirect-cloned ()
      "Detach copied Copilot tracking before editing a new indirect buffer."
      (when (and (buffer-base-buffer)
                 (or (bound-and-true-p copilot-mode)
                     my-copilot-indirect-root
                     (buffer-local-value 'copilot-mode (buffer-base-buffer))
                     (buffer-local-value 'my-copilot-indirect-root
                                         (buffer-base-buffer)))
                 (not (eq my-copilot-indirect-initialized (current-buffer))))
        (let* ((indirect (current-buffer))
               (root (buffer-base-buffer))
               (enabled (or (bound-and-true-p copilot-mode)
                            my-copilot-indirect-enabled))
               (id copilot--track-changes-id)
               (owner (and id
                           (seq-find
                            (lambda (buffer)
                              (and (not (eq buffer indirect))
                                   (eq id (buffer-local-value
                                           'copilot--track-changes-id buffer))))
                            (buffer-list))))
               (my-copilot-indirect-switching t)
               ready)
          (setq-local my-copilot-indirect-initialized indirect)
          ;; Never unregister the copied ID: its tracker belongs to the source.
          ;; Detach our lists first, without mutating their shared cons cells.
          (setq-local copilot-mode nil
                      copilot--track-changes-id nil)
          (when id
            (setq-local track-changes--trackers (remq id track-changes--trackers)
                        track-changes--clean-trackers
                        (remq id track-changes--clean-trackers)
                        track-changes--disjoint-trackers
                        (remq id track-changes--disjoint-trackers))
            (when (null track-changes--trackers)
              (remove-hook 'before-change-functions #'track-changes--before t)
              (remove-hook 'after-change-functions #'track-changes--after t)
              (dolist (variable '(track-changes--state track-changes--before-beg
                                  track-changes--before-end track-changes--before-string
                                  track-changes--before-no track-changes--before-clean
                                  track-changes--buffer-size))
                (kill-local-variable variable))))
          (when owner (my-copilot-indirect-manage owner root t))
          (when (buffer-local-value 'copilot-mode root)
            (my-copilot-indirect-manage root root t))
          (my-copilot-indirect-manage indirect root enabled)
          (unwind-protect
              (progn
                (when enabled (my-copilot-indirect-try-activate indirect))
                (setq ready t))
            (unless ready
              (kill-buffer indirect)
              (my-copilot-indirect-resume root))))))

    (add-hook 'copilot-mode-hook #'my-copilot-indirect-mode-changed)
    (add-hook 'pre-command-hook #'my-copilot-indirect-before-command -90)
    (add-hook 'before-change-functions #'my-copilot-indirect-before-change -100)
    (add-hook 'clone-indirect-buffer-hook #'my-copilot-indirect-cloned -100)
    (advice-add 'copilot--ensure-doc-open :before
                #'my-copilot-indirect-before-command))
#+end_src

* Gnus の新着メール通知

現在の =nnml= と =mail-sources= による受信時に、新着件数をまとめて通知します。
Windows の GUI Emacs では標準のトレイ通知、Fedora では D-Bus 経由の
デスクトップ通知を使います。Fedora は D-Bus 対応の Emacs と、ログイン中の
デスクトップ通知サービスが必要です。

=.gnus= の既存の =gnus-demon-scan-mail= が10分間隔で受信するため、
通知もその受信時に出ます。Gnus を起動したままにしてください。
手動で受信した場合も通知します。保存済みの未読メールでは通知せず、
今回新たに取り込んだメールだけを対象にします。=spam= グループは除外します。
通知には件数だけを表示します。

再起動後に =M-x my-gnus-notification-test= で通知表示を確認できます。

* Gnus のアドレス帳と送信元アドレス

GNU ELPA の BBDB を Gnus と Message に接続します。既存の =bbdb= ファイルを
アドレス帳として使い、閲覧したメールと送信したメールから連絡先を登録・更新します。
迷惑メールの =spam= グループでは新規登録しません。

=C-c b b= でアドレス帳を開き、=C-c b c= でメールの宛先欄を補完できます。
宛先欄の通常の補完にも BBDB の候補を出し、本文では従来の Corfu 補完を使います。

自分のアドレスは Gnus の設定にある =user-mail-address= と、将来
=gnus-posting-styles= に追加する =address= から取得します。返信時は元メールの
宛先に一致するアドレスを =From= に選びます。新規メールの送信元は Gnus の
既存設定に従います。

#+begin_src emacs-lisp
  (use-package bbdb
    :ensure t
    :pin gnu
    :bind (("C-c b b" . bbdb)
           ("C-c b c" . bbdb-complete-mail))
    :preface
    (defun my-gnus-own-addresses ()
      "Return mail addresses configured for this Gnus session."
      (delete-dups
       (delq nil
             (cons (and (stringp user-mail-address) user-mail-address)
                   (when (boundp 'gnus-posting-styles)
                     (mapcar (lambda (style)
                               (let ((address (cadr (assq 'address (cdr style)))))
                                 (and (stringp address) address)))
                             gnus-posting-styles))))))

    (defun my-gnus-own-address-p (address)
      "Return non-nil when ADDRESS belongs to this Gnus user."
      (member-ignore-case address (my-gnus-own-addresses)))

    (defun my-gnus-bbdb-auto-action ()
      "Avoid creating contacts from the Gnus spam group."
      (if (and (eq (bbdb-mua) 'gnus)
               (boundp 'gnus-newsgroup-name)
               (stringp gnus-newsgroup-name)
               (string-match-p "\\(?:\\`\\|[:.]\\)spam\\'"
                               gnus-newsgroup-name))
          'search
        'create))

    (defun my-gnus-bbdb-init ()
      "Connect BBDB and refresh the user's mail addresses after Gnus starts."
      (require 'bbdb)
      (bbdb-initialize 'gnus 'message)
      (bbdb-mua-auto-update-init 'gnus 'message)
      (let ((addresses (my-gnus-own-addresses)))
        (when addresses
          (setq bbdb-user-mail-address-re
                (concat "\\`" (regexp-opt addresses t) "\\'")))))

    :init
    (add-hook 'gnus-started-hook #'my-gnus-bbdb-init)
    :custom
    (bbdb-file (locate-user-emacs-file "bbdb"))
    (bbdb-complete-mail nil)
    (bbdb-mua-auto-action #'my-gnus-bbdb-auto-action)
    (bbdb-mua-pop-up nil)
    (message-expand-name-standard-ui t)
    (message-alternative-emails #'my-gnus-own-address-p))

* Consult による検索と移動

[[https://github.com/minad/consult#use-package-example][Consult README の use-package 設定例]]に沿って、GNU ELPA から導入します。
Vertico による候補表示と Nucleo による照合を利用します。
キー割り当てからコマンドを遅延読み込みし、レジスタと xref の連携は
=:init= で起動時から有効にします。

** キー割り当て

README の設定例と同じキーを使用します。主な操作は次のとおりです。

- =C-c M-x=: 現在のモードのコマンド、=C-c h=: 履歴、=C-c k=: キーボードマクロを選択します。
- =C-c m=: man ページ、=C-c i=: Info マニュアルを検索します。
- =C-x b=: バッファ・最近使ったファイル・ブックマークから選択します。
  =C-x 4 b= / =C-x 5 b= / =C-x t b= は別ウィンドウ・フレーム・タブで開きます。
- =C-x r b=: ブックマーク、=C-x p b=: プロジェクト内のバッファ、
  =C-x M-:=: 実行済みの複合コマンドを選択します。
- =M-#= / =M-'= / =C-M-#=: レジスタの読み込み・保存・選択を行います。
- =M-y=: キルリングから選択します。直前の操作が yank の場合はその内容を置き換えます。
- =M-g g= / =M-g M-g=: 行番号、=M-g i= / =M-g I=: 現在／複数バッファの Imenu へ移動します。
- =M-g e= / =M-g r= / =M-g f=: コンパイルエラー・Grep の一致・Flymake 診断へ移動します。
- =M-g o= / =M-g m= / =M-g k=: アウトライン・マーク・グローバルマークへ移動します。
- =M-s d= / =M-s c=: find / locate でファイルを探します。
- =M-s g= / =M-s G= / =M-s r=: grep / git grep / ripgrep で
  プロジェクト内（プロジェクト外では現在のディレクトリ）を検索します。
- =M-s l= / =M-s L=: 現在／複数バッファの行を検索します。
- =M-s k= / =M-s u=: 一致する行だけを残す／一時的に表示します。
  =M-s k= はバッファの内容を変更します。
- =M-s e=: Isearch の履歴を選択します。Isearch 中は =M-e= からも使え、
  =M-s l= / =M-s L= で検索文字列を引き継いで行検索へ移れます。
- ミニバッファ内の =M-s= / =M-r=: 入力履歴を選択します。

** プレビューと候補の絞り込み

レジスタのプレビューを Consult の表示へ置き換え、0.5 秒後に表示します。
xref による参照・定義の候補も Consult で選択します。
テーマは 0.2 秒、ファイルを読み込む検索やブックマークなどは 0.4 秒待って
プレビューし、バッファ内の行検索などは即座にプレビューします。
=C-g= で選択を取り消せます。

=<= に続けてカテゴリのキーを押すと候補を絞り込めます。
=consult-buffer= では =b SPC= でバッファ、=f SPC= で最近使ったファイルに
絞り込むこともできます。絞り込みキーの候補は既存の which-key で確認できます。

** 外部コマンドと検索式

=M-s r= は =rg=、=M-s d= は =find=、=M-s c= は =locate= と検索用データベース、
=C-c m= は =man= の外部コマンドを使用します。
grep 系コマンドでは =#検索式#絞り込み= の前半を外部コマンドへ渡し、
後半を Nucleo で照合します。日本語の Migemo 照合はこの後半や
=consult-line= などの Emacs 内の候補に対して働きます。

=rg= のプロセス出力は UTF-8 に指定します。ファイル名の区切りに NUL を含む
検索結果では文字コードの自動判定が働かず、日本語のファイル名や本文が
=\343\201...= のように表示されることがあるためです。
Windows で検索語を渡すときはシステムの文字コードを使い、日本語の引数が
文字化けしないようにします。=consult-find= は Scoop の Git に同梱された
GNU find がある場合にそれを使います。Windows 標準の =find.exe= は
別用途のコマンドであり、ファイル名検索には使えません。
リモートディレクトリでは接続先の =find= を使います。

Windows の =consult-grep= も、Scoop の Git に同梱された GNU grep がある場合に
それを使い、UTF-8 の検索結果と日本語ファイル名を正しく受け取ります。
リモートディレクトリでは接続先の =grep= を使います。
GNU grep には ripgrep の =--encoding= に相当する変換指定がないため、
CP932 などを指定して検索するときは次の専用 ripgrep コマンドを使います。

** 文字コードを選んで ripgrep 検索する

=M-x my-consult-ripgrep-with-encoding= は、検索の前に対象ファイルの文字コードを
Emacs 標準の =read-coding-system= で毎回尋ねます。通常の文字コード一覧から
=utf-8=、=cp932=、=euc-jp= などを選べます。
最初の既定値は =utf-8= で、次回からは前回の選択を既定値にします。
選択は Savehist で保存し、Emacs の再起動後も引き継ぎます。
=C-u M-x my-consult-ripgrep-with-encoding= では検索先も指定できます。

選択した Emacs の名前を ripgrep の名前へ変換し、対応を確認してから検索します。
たとえば =cp932= は =shift_jis= に変換します。=-dos= / =-unix= などの改行形式は
検索用の文字コード指定から除きます。Emacs 独自の形式など、ripgrep が対応しない
ものを選んだ場合は検索せずに通知します。実際の変換規則は ripgrep に従うため、
Emacs の同名の形式と細部が異なる場合があります。

選んだ文字コードはその検索だけに適用し、結果は UTF-8 で受け取ります。
元ファイルは変更しません。UTF-8 と CP932 が混在する場合は、各文字コードで
検索してください。通常の =M-s r= と =consult-ripgrep= の動作はそのままです。

  (use-package consult
    :ensure t
    :pin gnu
    :preface
    (defvar consult-ripgrep-args)
    (defvar my-consult-ripgrep-encoding 'utf-8
      "Last file encoding selected for ripgrep searches.")

    (defun my-consult-ripgrep-encoding-name (coding)
      "Translate Emacs CODING to a ripgrep encoding label."
      (let* ((base (coding-system-base coding))
             (mime (coding-system-get base :mime-charset)))
        (cond
         ((eq base 'japanese-cp932) "shift_jis")
         ((memq base '(utf-8 utf-8-with-signature)) "utf-8")
         ((eq (coding-system-get base :coding-type) 'utf-16)
          (if (eq (coding-system-get base :endian) 'little)
              "utf-16le"
            "utf-16be"))
         (t (symbol-name (or mime base))))))

    (defun my-consult-ripgrep-check-encoding (encoding)
      "Check that ripgrep supports ENCODING, without searching files."
      (let ((program (car (consult--build-args consult-ripgrep-args)))
            (coding-system-for-read 'utf-8-unix))
        (with-temp-buffer
          (unless (memq (process-file program nil t nil
                                      "--no-config" (concat "--encoding=" encoding)
                                      "--regexp=." "--" "-")
                        '(0 1))
            (user-error "ripgrep で文字コード %s を利用できません: %s"
                        encoding (string-trim (buffer-string)))))))

    (defun my-consult-ripgrep-with-encoding (&optional dir initial)
      "Choose a file encoding, then search DIR with ripgrep.
  Always prompt, using the previous choice as the default.
  DIR and INITIAL have the same meaning as in `consult-ripgrep'."
      (interactive "P")
      (require 'consult)
      (let* ((saved (if (stringp my-consult-ripgrep-encoding)
                        (intern-soft (downcase my-consult-ripgrep-encoding))
                      my-consult-ripgrep-encoding))
             (choice (read-coding-system
                      "検索対象の文字コード: "
                      (if (and saved (coding-system-p saved)) saved 'utf-8)))
             (encoding (my-consult-ripgrep-encoding-name choice)))
        (my-consult-ripgrep-check-encoding encoding)
        (let ((consult-ripgrep-args
               (append (ensure-list consult-ripgrep-args)
                       (list (concat "--encoding=" encoding)))))
          (setq my-consult-ripgrep-encoding choice)
          (consult-ripgrep dir initial))))

    :bind (;; Mode commands, history, and help
           ("C-c M-x" . consult-mode-command)
           ("C-c h" . consult-history)
           ("C-c k" . consult-kmacro)
           ("C-c m" . consult-man)
           ("C-c i" . consult-info)
           ([remap Info-search] . consult-info)
           ;; Buffers, bookmarks, and projects
           ("C-x M-:" . consult-complex-command)
           ("C-x b" . consult-buffer)
           ("C-x 4 b" . consult-buffer-other-window)
           ("C-x 5 b" . consult-buffer-other-frame)
           ("C-x t b" . consult-buffer-other-tab)
           ("C-x r b" . consult-bookmark)
           ("C-x p b" . consult-project-buffer)
           ;; Registers and kill ring
           ("M-#" . consult-register-load)
           ("M-'" . consult-register-store)
           ("C-M-#" . consult-register)
           ("M-y" . consult-yank-pop)
           ;; Navigation
           ("M-g e" . consult-compile-error)
           ("M-g r" . consult-grep-match)
           ("M-g f" . consult-flymake)
           ("M-g g" . consult-goto-line)
           ("M-g M-g" . consult-goto-line)
           ("M-g o" . consult-outline)
           ("M-g m" . consult-mark)
           ("M-g k" . consult-global-mark)
           ("M-g i" . consult-imenu)
           ("M-g I" . consult-imenu-multi)
           ;; Search
           ("M-s d" . consult-find)
           ("M-s c" . consult-locate)
           ("M-s g" . consult-grep)
           ("M-s G" . consult-git-grep)
           ("M-s r" . consult-ripgrep)
           ("M-s l" . consult-line)
           ("M-s L" . consult-line-multi)
           ("M-s k" . consult-keep-lines)
           ("M-s u" . consult-focus-lines)
           ;; Isearch integration
           ("M-s e" . consult-isearch-history)
           :map isearch-mode-map
           ("M-e" . consult-isearch-history)
           ("M-s e" . consult-isearch-history)
           ("M-s l" . consult-line)
           ("M-s L" . consult-line-multi)
           ;; Minibuffer history
           :map minibuffer-local-map
           ("M-s" . consult-history)
           ("M-r" . consult-history))
    :init
    (with-eval-after-load 'savehist
      (add-to-list 'savehist-additional-variables 'my-consult-ripgrep-encoding))
    (advice-add #'register-preview :override #'consult-register-window)
    (setq register-preview-delay 0.5
          xref-show-xrefs-function #'consult-xref
          xref-show-definitions-function #'consult-xref)
    :config
    (modify-coding-system-alist
     'process "\\(?:\\`\\|[/\\\\]\\)rg\\(?:\\.exe\\)?\\'"
     (cons 'utf-8-unix
           (if (eq system-type 'windows-nt) locale-coding-system 'utf-8-unix)))
    (when (eq system-type 'windows-nt)
      (when-let* ((profile (getenv "USERPROFILE"))
                  (find (expand-file-name "scoop/apps/git/current/usr/bin/find.exe"
                                          profile))
                  ((file-executable-p find)))

                   (cdr args)))))
        (modify-coding-system-alist
         'process (concat "\\`" (regexp-quote grep) "\\'")

    (consult-customize

[[https://github.com/minad/marginalia#configuration][Marginalia README]] に沿って GNU ELPA から導入し、
ファイル情報やコマンドの説明などを補完候補に表示します。
Vertico と組み合わせて使えます。ミニバッファの =M-A= で

#+begin_src emacs-lisp
  (use-package marginalia
    :ensure t
    :pin gnu
    :bind (:map minibuffer-local-map
                ("M-A" . marginalia-cycle))
    :init

#+end_src

* Embark による候補やポイント上の操作

[[https://github.com/oantolin/embark#installation][Embark README]] に沿って GNU ELPA から導入します。
=C-.= でミニバッファの選択候補やポイント上の対象に応じた操作を選び、
=C-;= で対象の既定の操作を実行します。=C-h B= はキー割り当ての一覧です。
=C-.= の後に =S= で候補を一覧バッファに集め、=E= で候補に適したモードへ
書き出せます。Vertico の候補は追加設定なしで対象になります。

プレフィックスキーの後の =C-h= は補完付きのキー一覧を開きます。
既存の which-key は、プレフィックス入力後に待ったときの案内を引き続き表示します。
後述の which-key 設定では、=C-h= を Embark に任せるようにします。

#+begin_src emacs-lisp
  (use-package embark
    :ensure t
    :pin gnu
    :commands (embark-prefix-help-command)
    :bind (("C-." . embark-act)
           ("C-;" . embark-dwim)
           ("C-h B" . embark-bindings))
    :init
    (setq prefix-help-command #'embark-prefix-help-command))
#+end_src

Embark と Consult を連携させる =embark-consult= も GNU ELPA から導入します。
Consult の検索結果を書き出せるようになり、候補一覧では対応する候補を
ポイントの移動に合わせてプレビューします。

#+begin_src emacs-lisp
  (use-package embark-consult
    :ensure t
    :pin gnu
    :after (embark consult)
    :hook (embark-collect-mode . consult-preview-at-point-mode))
#+end_src

* 編集履歴を Vundo でたどる

GNU ELPA の Vundo は、現在のバッファの編集履歴を木として表示します。
=C-x u= または =M-x vundo= で開き、=f= / =b= で前後、=n= / =p= で分岐を移動します。
=RET= で選択した状態を確定し、=q= または =C-g= では変更を取り消して終了します。
通常の =C-/= による undo もそのまま使えます。

#+begin_src emacs-lisp
  (use-package vundo
    :ensure t
    :pin gnu
    :bind ("C-x u" . vundo))
#+end_src

* 変更箇所を diff-hl で表示する

GNU ELPA の diff-hl は、バージョン管理下のファイルで保存済みの変更を表示します。
GUI ではフリンジを使用し、端末では既定のマージンへのフォールバックを使用します。
Dired にもファイルの変更状態を表示し、Magit の更新後に表示を更新します。
変更箇所の移動には =C-x v [= と =C-x v ]= を使えます。

#+begin_src emacs-lisp
  (use-package diff-hl
    :ensure t
    :pin gnu
    :demand t
    :hook
    (dired-mode . diff-hl-dired-mode)
    (magit-post-refresh . diff-hl-magit-post-refresh)
    :config
    (global-diff-hl-mode 1))
#+end_src
